## 🚀 关于我们

欢迎来到 VoxelLink 团队！我们致力于打造 Minecraft Java 版相关作品（Spigot 插件、Fabric 模组、工具库），为玩家与服务器管理员提供更好的游玩与运维体验。

团队 flagship 项目 **[VoxelLink](https://github.com/VoxelLinkCN/VoxelLink)** 是一款连接 Minecraft 与 QQ、Discord 等聊天平台的桥接插件：多平台支持（Bukkit / Folia / Velocity）、业务逻辑脚本化（GraalJS）、支持从 AQQBot 一键迁移，让服主用一套配置打通游戏内外。

我们欢迎更多开发者加入我们，如有意愿可以通过下方联系方式联系我们！
